Feature tour

Everything you need, nothing you don't

Six features carry the whole product. Each one works the moment you open a room — no setup screens in between.

Type together, see it land instantly

Every keystroke broadcasts over Supabase Realtime in well under a second, with a durable save to Postgres a beat behind it. Open the same room on two devices and watch them stay in lockstep — presence, typing indicators, and cursor position included.

Lock a note behind a passphrase only you hold

Turn on AES-256-GCM encryption and JotRelay encrypts the note client-side before it ever leaves your browser. The passphrase is never sent or stored — forget it, and the note can't be recovered by anyone, including us.

Hand off files as easily as text

Drag a file into the room and it's ready to download on every connected device in seconds — up to 10 MB each, multiple files at once, with signed links that expire on their own.

Every room, exactly as open as you want it

Set a passcode, lock editing across every device, put an expiry on the room, or cap it to a fixed number of devices — all from the Settings panel, no account required to configure any of it.

Share the read, keep the write

Generate a read-only link or a short spoken code that lets anyone view the room without editing a word — perfect for sending a draft to a client or a stakeholder who just needs to look.

Zero sign-up, zero friction

There's no login, no email, no password to create. Open JotRelay, hit Create a Room, and you're writing — the room link itself is the only credential you need.

Privacy

JotRelay is anonymous by default, but not private by default.

  • Normal rooms do not require accounts.
  • Editable room links are anonymous room paths.
  • Anyone with the editable room path can edit that room.
  • Read-only share links hide the room name but are still secret bearer links.
  • Room text and file metadata are stored in Supabase.
  • Uploaded files are stored in Supabase Storage.
  • Browser localStorage may store drafts, preferences, theme, device name, and similar local data.
  • Encrypted room text requires the passphrase.
  • If the passphrase is forgotten, encrypted room text cannot be recovered.
  • Uploaded files are encrypted only in a room with encryption turned on, and only from the moment it was turned on — earlier uploads and files in unencrypted rooms stay plaintext.
  • The site owner/admin may access unencrypted rooms/files for maintenance, troubleshooting, and abuse handling.
  • Contact form submissions go through Web3Forms only if configured.
  • Web3Forms `access_key` is a public frontend key, not a private server secret.
  • View-once is a convenience feature, not a secure destruction guarantee. A viewer may copy, screenshot, save, or otherwise preserve content before it clears.
  • No analytics or ad cookies are used unless actually added to the app.

About JotRelay

JotRelay is a simple anonymous shared notepad for quick collaboration. Create a room, share the editable link, or generate a hidden read-only share link.

  • Anonymous rooms
  • Live syncing
  • Editable room links
  • Hidden read-only share links
  • Optional passcode, encryption, expiration, and view-once settings
  • File handoff
  • Report room option

Security note: JotRelay is link-based. Anyone with an editable room link can edit that room. Read-only links hide the room path but still act like bearer links. View-once is convenience-only and not a secure destruction guarantee.
